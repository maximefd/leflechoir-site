# Police du SVG de l'API

`archivo-narrow-700.ttf` : **Archivo Narrow** Bold (Omnibus-Type), sous [SIL Open Font License 1.1](https://openfontlicense.org/), notice dans [`OFL.txt`](OFL.txt). Copie de `frontend/public/fonts/`.

L'API ouverte l'embarque dans les grilles qu'elle dessine en SVG (`grid_render.py`). La découpe des définitions est calculée pour cette police : un SVG qui en prendrait une autre déborderait. La licence permet d'embarquer la police dans un document.
